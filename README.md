# NodeJS Global Mentoring Program

## Description

This project is a CPU monitor that displays the most CPU-intensive process and logs it to a file every second.

## Installation

Prerequisites: Before installing the project, make sure you have Node.js and npm installed on your system.


- node npm

```
npm install
```


## Usage

The 'npm run random' command generates a random number between two specified numbers. The '.random' command inside the REPL also generates a random number between two specified numbers. The '.help' command inside the REPL displays a list of available commands. The 'npm run start' command starts the CPU monitor.

```
npm run random

//inside REPL
.random num1 num2
.help

npm run start

```

## Dev notes

To use the debugger, 'nodemon --inspect' turned on debugging for the back-end code. Then, open the Chrome DevTools and navigate to the ['chrome://inspect/#devices'](chrome://inspect/#devices) URL to start debugging.
