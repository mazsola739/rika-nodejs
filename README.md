# NodeJS Global Mentoring Program

## Description

This project is NodeJs Global Mentoring practice project

## Installation

Prerequisites: Before installing the project, make sure you have Node.js and npm installed on your system.


- node npm

```
npm install
```


## Usage

- Module 1: The 'npm run random' command generates a random number between two specified numbers. The '.random' command inside the REPL also generates a random number between two specified numbers. The '.help' command inside the REPL displays a list of available commands. 

```
npm run random

//inside REPL
.random num1 num2
.help
```

- Module 2: The 'npm run start' command starts the CPU monitor.

```
npm run start
```

- Module 3: 
  - The 'npm run task1' command starts the event emitter.
  
  ```
  npm run task1
  ```
  - The 'npm run task2' command starts the event emitter extended with elapsed time measurement.

  ```
  npm run task2
  ```
  - the 'npm run task3' command starts the CSV to json converter

  ```
  npm run task3
  ```

- Module 4: The 'npm run test' command runs the test suite for the public holiday service, while the 'npm run test:coverage' command runs the test suite and generates a code coverage report in the console."

```
npm run test
npm run test:coverage
```

- Module 5: The 'npm run server' command runs REST API server for users and their hobbies"

```
npm run server
```

- Module 6: The 'npm run express' command runs checkout service for users which sells different types of products"

```
npm run express
```
## Dev notes

To use the debugger, 'nodemon --inspect' turned on debugging for the back-end code. Then, open the Chrome DevTools and navigate to the ['chrome://inspect/#devices'](chrome://inspect/#devices) URL to start debugging.
